

# 智建团队 (Smart Team Build)

> 一个基于微信小程序云开发的智能化团队组建与技能匹配平台。

## 1. 项目简介

本项目旨在帮助用户高效地组建和管理团队，特别是在竞赛或项目开发场景下。平台集成了完整的用户体系、技能评估系统、团队管理工具以及智能匹配引擎。通过 AI 技术的辅助，平台能够自动分析用户技能并生成团队需求建议，极大地简化了团队招募和信息整理的流程。

## 2. 核心功能

*   **智能团队匹配**：
    *   **缺失技能计算**：系统自动分析团队构成，计算当前团队缺少的技能。
    *   **匹配池机制**：用户可以进入匹配池，根据技能互补性寻找合适的队伍或队员。
*   **用户与技能管理**：
    *   **技能评估**：支持用户手动录入技能，并提供 AI 辅助评级功能。
    *   **个人档案**：支持微信头像上传、个人信息完善与更新。
*   **竞赛管理**：
    *   **文档解析**：支持上传 Word 文档，利用 `mammoth` 库解析并提取内容。
    *   **AI 生成**：集成 AI 接口，自动生成竞赛详情摘要或解析文档内容。
*   **团队协作**：
    *   **申请与审批**：处理队员加入、导师指导等请求。
    *   **状态同步**：实时同步团队的参与状态（进行中、已完成等）与成员变动。

## 3. 技术架构

*   **前端框架**：微信原生小程序
*   **UI 组件库**：Vant Weapp (`@vant/weapp`)
*   **后端服务**：微信云开发 (Serverless)
    *   **云函数**：处理核心业务逻辑（位于 `cloudfunctions/`）
    *   **云数据库**：存储用户、团队、竞赛等核心数据
*   **状态管理**：Flux 风格的前端全局状态管理 (`store/`)
*   **主要依赖**：
    *   `mammoth`：用于 Word (.docx) 文档到 HTML 的转换。
    *   `axios`：云函数中用于调用外部 AI 接口。

## 4. 项目结构

```
├── cloudfunctions/             # 云函数目录
│   ├── competitionApi/         # 竞赛相关：文件上传、AI生成、CRUD
│   ├── matching_poolApi/       # 匹配池：进入/退出、列表查询
│   ├── requestApi/             # 请求处理：加入团队、导师申请
│   ├── teamsApi/               # 团队核心：成员管理、需求计算
│   ├── userAPI/                # 用户管理：技能、信息、绑定
│   └── skill_*/                # 技能的增删改查
├── miniprogram_npm/            # 小程序依赖包 (Vant Weapp 等)
├── pages/                      # 公共页面
├── subPackages/                # 业务功能子包
│   ├── admin/                  # 管理员模块
│   ├── competition/            # 竞赛详情页
│   ├── joined/                 # 已加入团队管理
│   ├── team/                   # 团队列表、创建、管理
│   └── user/                   # 个人中心、注册登录
├── store/                      # 前端状态管理
├── utils/                      # 工具函数
└── app.*                       # 小程序入口文件
```

## 5. 部署指南

1.  **环境准备**：确保已安装 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)。
2.  **项目导入**：使用微信开发者工具导入本项目，勾选“启用云开发”并选择或创建云环境。
3.  **部署云函数**：
    *   在 `cloudfunctions` 目录上右键，选择“上传并部署：云端安装依赖”。需依次部署所有云函数。
4.  **数据库配置**：
    *   登录 [微信公众平台](https://mp.weixin.qq.com/) 或在开发者工具中打开云开发控制台。
    *   创建以下集合 (Collection)：`users`, `teams`, `competitions`, `matching_pool`, `requests`, `skills`。
    *   根据业务需求配置集合的安全规则（权限）。

## 6. 注意事项

*   **AI 配置**：请在 `cloudfunctions/competitionApi/service.js` 中配置有效的外部 AI API Key (`AI_API_KEY`) 和接口地址 (`AI_URL`)。
*   **管理员权限**：初始管理员账号需手动在数据库中设置用户权限字段，或通过代码逻辑进行绑定。
